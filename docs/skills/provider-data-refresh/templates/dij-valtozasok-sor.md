# Díjváltozás-napló — sor-sablon

Work file: `provider-data-refresh/_gyujto/dij-valtozasok-YYYY-Qn.md` (Q a frissítés dátuma szerint),
`platform.work_file.append`-del a végére; a legújabb alul. Append előtt olvasd el a fájlt.

    - **YYYY-MM-DD · [Szolgáltató neve]:** [↑ / ↓ / ↔] *Tétel röviden* — régi → új (ha értelmezhető) — [elemzés fájlneve] (proposal_id: …)

Irány: ↑ kereskedői költség nőtt · ↓ csökkent · ↔ azonos összeg, de a tétel/feltétel/megnevezés
változott (vagy nem numerikusan összehasonlítható).
Ha nem volt díjváltozás, ne írj bejegyzést.
